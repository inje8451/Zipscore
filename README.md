## 0. v4.1 수정 — 가격 기준을 '인천 전체'로 (2026.11.23)

인제님 지시: *"당연히 인천 전체 기준으로 해야지!!"*

v4.0은 시세 점수를 **권역(zone) 안 백분위**로 매겼습니다. 그래서 미추홀·부평·구월의 5~7억대 단지가 권역 1등이 되어 가격에서 만점을 받고, 송도 대장(84㎡ 12~13억)이 권역 2~3등으로 밀려 오히려 감점되는 역전이 생겼습니다.

| # | v4.0 | v4.1 |
|---|---|---|
| 시세 기준 | 권역 안 84㎡ 시세 상위도 (7점) | **인천 전체 443단지(실거래 표본) 안 ㎡당 실거래가 순위** (10점) — 권역 구분 없음 |
| 구간 | 상위 10/25/50/75% → 7/6/4/3/2 | 인천 1~22위 10점 · 23~45위 9점 · 46~89위 8점 · 90~156위 6점 · 157~222위 5점 · 223~310위 3점 · 311~443위 2점 · 표본 없음 2점 |
| 매매 회전율 | 8점 (0.4~3.0% 7구간) | 5점 (0.4~2.5% 6구간, 같은 컷을 비례 축소) |
| 합계 | 15점 | 15점 (10 + 5) |

결과: **가격 점수가 시세 만점을 주는 단지가 송도 상위 22곳(㎡당 988만원 이상)뿐**이 됐습니다. 더샵아르테(㎡당 833만원·인천 58위)는 15점 만점 → **13점**, 송도더샵퍼스트파크(㎡당 1,429만원·인천 2위)는 13점 → **14점**으로 뒤집혔습니다.

## 7. 한계 (사이트에도 표기)

- 거리는 **직선거리**입니다. 도보 동선(횡단보도·경사·우회)과 다를 수 있습니다.
- 초등학교는 **가장 가까운 학교** 기준이며 실제 **배정 학교와 다를 수 있습니다**(학교군·추첨).
- 시세는 최근 6개월 **신고분 중위값**이라 층·향·수리 상태·특수거래에 따라 달라집니다. 표본이 3건 미만이면 대표 평형 값을 쓰고, 표본이 없으면 "실거래 표본 없음"으로 표시합니다(75곳). ㎡당가 이상치(중위 대비 45% 미만·1.8배 초과)는 제외합니다.
- 인프라는 **OpenStreetMap 등록 시설** 기준이라 누락된 시설이 있을 수 있습니다.
- 미래가치는 2030년까지 **개통이 확정된** GTX-B 3역·7호선 청라연장 종점만 반영합니다. 청라연장 신설역(001~005)은 역명·좌표 고시 전이라 제외했습니다.
- 6문항 간이 진단은 사용자가 고른 구간으로 계산하는 별도 도구입니다.
