# 🏢 집스코어 ZIPSCORE — 인천 아파트 100점 성적표

인천 8개 권역 **120개 실제 아파트 단지**를 교통·학군·단지 스펙·생활 인프라·가격/환금성·미래 가치 6개 영역, 100점 만점으로 채점한 웹 성적표입니다.

- 사이트: **https://inje8451.github.io/Zipscore/**
- 5개 탭: 📊 성적표 · 💰 예산찾기 · ⚔️ 배틀 · 🏆 인천 120위 랭킹 · 🗺️ 무료 지도(Leaflet + OpenStreetMap)
- 💰 **예산찾기**: 연 소득·보유 현금·기존 대출·금리·LTV(일반 70% / 생애최초 80%)로 DSR 40% 최대 대출과 매수 가능 예산을 계산해, 예산 안의 단지를 집스코어 점수순으로 추천
- 🗺️ **지도**: 단지 실제 위경도 좌표에 점수 핀을 띄우고, 핀 팝업 카드에서 성적표로 바로 이동. 권역 퀵 점프(flyTo)
- 단지 사실(세대수·준공·최근 6개월 매매)은 국토교통부 공동주택 기본정보 집계(2026.09), 좌표는 카카오맵 기준
- 모든 계산은 브라우저에서만 실행됩니다(서버·개인정보 수집 없음). 84㎡ 시세는 추정 참고값이며, 대출 한도는 단순 시뮬레이션입니다.
